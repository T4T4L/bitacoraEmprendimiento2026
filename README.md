# Bitácora - Emprendimiento UAI

Bienvenido al repositorio de la Bitácora del ramo de **Emprendimiento** de la **Universidad Adolfo Ibáñez (UAI)**.

Este sitio web tiene como propósito registrar los avances, presentaciones y entregables semanales desarrollados a lo largo del curso por nuestro equipo. 

## 🌐 Sitio Web

Puedes visitar la versión en vivo de nuestra bitácora en el siguiente enlace:

> **https://t4t4l.github.io/bitacoraEmprendimiento2026/**

## 📂 Estructura del Proyecto

- `index.html`: Página principal que contiene el menú de navegación a las distintas semanas y entregas.
- `css/`: Hojas de estilo que le dan diseño y formato visual al sitio.
- `semanas/`: Vistas detalladas del avance realizado semana a semana.
- `entregas/`: Archivos y presentaciones de las entregas oficiales del ramo.
- `resources/`: Imágenes y recursos estáticos (logos, gráficos, etc.) utilizados en la web.
